# Specification conflicts and implementation decisions

This file documents differences without changing the business acceptance criteria. Original Python and .NET specs are left unchanged.

| ID | Severity | Reference | Conflict and documented treatment |
| --- | --- | --- | --- |
| D-01 | BLOCKER | `tasks.md` T-21 / `spec.md` HU-06 / `api-contract.md` loans | An API-only demo generator cannot produce 3 overdue items using newly issued loans with server-clock `loaned_at` and a +14d due date. **Unresolved:** do not add backdating APIs, bypass SQL, or falsely claim the acceptance test passed. Ask for authorized clock/fixture or waiver. |
| D-02 | HIGH | ADR-002 / `data-model.md` §3 | Optimistic concurrency witness is required but the exact book schema has no version field. **Selected compatible approach:** PostgreSQL atomic conditional `UPDATE ... WHERE available_copies > 0 RETURNING` as the concurrency compare-and-swap witness, preserving the physical model and last-copy correctness. This is a documented *interpretation*, not a claim of a stored version; explicit ADR-002 version-column compliance remains unresolved. |
| D-03 | HIGH | `tasks.md` T-18 / original docs policy | Updating model documentation is required when T-18 CHECKs are installed. **Treatment:** record actual constraints in this adaptation and keep archived baseline references intact. |
| D-04 | HIGH | `constitution.md` language / learner instructions | Reference Spanish prose and UI error messages conflict with required English conversion. **Treatment:** code and all newly authored documentation in English; keep stable English protocol fields/codes and original five category values. The user-visible error wording in the implementation is English, a consciously documented localization deviation. |
| D-05 | MEDIUM | `api-contract.md` §3.4 | `GET /books/{id}/cover` is defined in prose but omitted from the route table. **Treatment:** implement GET binary route because the contract explicitly references it. |
| D-06 | MEDIUM | `api-contract.md` §1 / `tasks.md` T-01 | Health route prefixed or unprefixed ambiguity. **Treatment:** expose both `GET /health` and `GET /api/v1/health` (exact same public payload). |
| D-07 | HIGH | HU-06 / optimistic locking ADR | Even correct per-book optimistic writes do not serialize loans for *different books* to the same member. **Treatment:** serialize the member's checkout eligibility within one PostgreSQL transaction by row-level lock on `member`; for books use atomic conditional updates. |
| D-08 | MEDIUM | HU-09 | Fractional-day overdue rounding is unspecified. **Treatment:** document floor of elapsed complete UTC days, minimum 1 once overdue; test both boundary cases. |
| D-09 | HIGH | `data-model.md` §3 / Laravel conventions | Framework default tables, singular/plural conventions, default timestamps and autogenerated ids violate schema. **Treatment:** explicit PostgreSQL migrations for six singular tables, no column defaults; framework metadata outside `library` business model; no domain tables in `infra`. |
| D-10 | MEDIUM | Python vs .NET `plan.md` | Password algorithms vary by reference. **Treatment:** Argon2id in PHP where available, behind application port; match required secrecy and verify hash. |
| D-11 | MEDIUM | `api-contract.md` error §2 | Unknown authorization code for missing/expired bearer token. **Treatment:** `INVALID_TOKEN` for unauthenticated requests, without exposing sensitive internals. |
| D-12 | HIGH | `constitution.md` immutable content / Spanish category seed | Translating fixed category values would change data and fail exact seed checks. **Treatment:** preserve exact values and UUIDs, document exception to localization. |

**Decision status:** D-01 and exact ADR-002 token requirement are **open** pending instructor clarification. The chosen compare-and-swap approach provides safety but should not be labeled as literal compliance with a stored version token. Never conceal deviations.
